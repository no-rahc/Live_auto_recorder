03

후처리 · 파일명

Post-Processing

녹화 완료 후 자동 후처리 여부를 설정합니다.

후처리 후 원본 파일을 삭제할지 여부를 설정합니다.

후처리 후 파일 이름에서 'fixed_' 접두사를 제거할지 여부를 설정합니다.

후처리/병합 완료파일을 지정된 경로로 자동 이동할지 설정합니다.

자동 이동할 경로 (예: D:/test)

후처리 작업 명령창을 항상 메인창이 아닌 새창에서 실행하도록 합니다.

등록된 채널의 방송이 시작되었는지 재탐색하는 간격을 설정합니다.
타임머신 플러그인 사용시 가능하면 120초 이상으로 권장합니다.

※ 간격이 너무 짧으면 IP밴이나 채널이 패싱되는 경우가 있습니다

설정 값 설명
{recording_time}녹화시작시간 (예: 240801_183507)
{start_time}방송 시작 날짜 (예: 2024-08-01)
{safe_live_title}방송 제목
{channel_name}스트리머 채널명
{record_quality}녹화 해상도
{frame_rate}녹화 프레임
{file_extension}파일 확장자
04

분할녹화

Split Recording

사용자가 지정한 분할녹화 시간만큼 파일을 나누어 녹화합니다.
3600초를 지정하면 녹화파일이 1시간씩 나누어 생성됩니다.

분할녹화 완료 후 자동 후속 후처리 여부를 설정합니다.

분할녹화 모드 사용시, 분할녹화 시간 가격을 설정합니다.

분할녹화시 분할 파일 사이의 누락된 부분이 없도록 앞/뒤 영상에 겹치는 시간을 설정합니다.
권장 겹침시간 : 6 ~ 10초, 0 이면 겹침 없음.

05

인코딩

Encoder

원본유지(스트림복사) 또는 용량절약(열화인코딩) 중 선택합니다.

사용할 비디오 코덱을 선택합니다.

코덱 사용 가능한 인코딩 프리셋
[x264 / HEVC] CPU만 사용 ultrafast / superfast / veryfast / faster / fast / medium / slow / slower / veryslow / placebo
[h264 / HEVC] 인텔 GPU veryfast / faster / fast / medium / slow / slower
[h264 / HEVC] 지포스 GPU
(NVENC 7세대 이상)		 p1 (ultrafast) / p2 (superfast) / p3 (veryfast) / p4 (faster) / p5 (fast) / p6 (medium) / p7 (slow)
[h264 / HEVC] 지포스 GPU
(NVENC 6세대 이하)		 default / slow / medium / fast / hp / hq / bd / ll / llhq / llhp / lossless / losslesshp
[h264 / HEVC] 라데온 GPU balanced / speed / quality

* NVENC 7세대 이상 지포스 GPU 가속 :
16, 20, 30, 40, 50 시리즈 이상만 지원 (GTX 1650 GDDR5 제외)

* NVENC 6세대 이하 지포스 GPU 가속 :
지포스600~900, 1000, GTX 1650 GDDR5 한정

비트레이트 모드와 퀄리티 모드 중 선택합니다.

퀄리티 모드 값 (예시) 설명
23~245~10% 화질저하, 약간의 용량 절약
26~2815~25% 화질저하, 용량 절약
32~3530~40% 화질저하, 용량 절약

퀄리티 값이 낮을수록 화질은 좋아지지만 파일 용량은 커집니다.
표는 x264 CPU 기준 추정치이며, GPU 가속이나 HEVC에서는 다를 수 있습니다.

평균 비트레이트 값을 설정합니다. 값이 낮을수록
화질이 떨어지고 용량이 줄어듭니다.
치지직 1080P 기준 8000k 값입니다.

(예: 5000k)

인코딩시 비트레이트 가변 폭의 최대값을 지정합니다.

(예: 7500k, 권장: 평균 비트레이트 값의 1.5~2배)

인코딩 시 화려하거나 복잡한 장면이 갑자기
늘어나거나 줄어드는 것을 부드럽게 관리하기
위한 임시 저장공간의 크기를 입력합니다.

(예: 15000k, 권장: 평균 비트레이트 값의 3~4배)

• Look-ahead: 다음 프레임을 사전 확인하여 인코딩 압축 효율을 높입니다.
• 장점: 선명도가 상승하고 용량이 줄어듭니다.
• 단점: 인코딩 속도가 느려집니다.

GPU 사용 인코더 낮은 압축효율 예시 높은 압축효율 예시
인텔 h264_qsv / hevc_qsv -look_ahead 1 -bf 2 -look_ahead 1 -look_ahead_depth 20 -bf 5
지포스 h264_nvenc / hevc_nvenc -rc-lookahead 10 -bf 2 -rc-lookahead 20 -bf 3
라데온 h264_amf / hevc_amf -preanalysis true -pa_lookahead_buffer_depth 10 -bf 2 -preanalysis true -pa_lookahead_buffer_depth 20 -bf 3

• 비교적 빠른 인코딩 속도와 적당한 화질 향상을 원한다면 낮은 압축효율
• 인코딩 속도가 느려져도 더 높은 화질 향상을 원한다면 높은 압축효율

• B-프레임이 0이면 look-ahead 효과가 거의 없습니다. 보통 -bf 2~4 권장.
• 일부 구형/특수 모델은 제한이 있습니다(예: 지포스 GTX 1630, 1650 GDDR5 등 B-프레임 제한).
• 인텔 QSV는 6세대(Skylake) 이상 지원(효율은 7세대+ 권장), 라데온은 RX 6000 이상 권장.

오디오 코덱을 선택합니다.
치지직 기본 오디오 코덱은 AAC 입니다.

오디오 비트레이트 값을 선택합니다.
치지직 오디오 비트레이트 최대값은 192k(원본) 입니다.

06

텔레그램 알림 설정

Telegram

이 옵션을 활성화하면 녹화 상태 변화(녹화 시작/중지 등)를 텔레그램으로 알림받을 수 있습니다.

※ 텔레그램 봇 토큰값은 웹페이지에서 암호화된 값으로 표시됩니다


(1) 텔레그램 앱에서 누르고 @BotFather를 검색하여 대화를 시작합니다.

(2) /newbot 명령어를 입력하고, ①봇이름을 정합니다

(3) 이어서 ②사용자명을 정합니다. 봇이름_bot 으로 입력합니다(_bot)

- 단, 봇이름은 다른 이용자와 중복된 이름으로 지을 수 없으니 주의

- 잘 모르겠으면, 일반 웹사이트 ID처럼 영문자+숫자 사용하는걸 추천

(4) BotFather가 HTTP API: 봇 토큰을 제공하면, 복사하여 입력란에 붙여넣으세요

(5) 봇 토큰을 제공한 채팅내용 상단에 t.me/봇이름_bot을 접속합니다

(6) 새롭게 접속한 봇 채팅방에 시작(start)를 누르면 자동으로 /start가 입력됩니다

(7) /start 가 자동 입력된 뒤 아무 메시지나 봇 채팅방에 입력합니다.

(8) 웹브라우저(크롬 등)을 열어 주소창에 본인 토큰값을 적용하여 입력합니다.

https://api.telegram.org/bot토큰값/getUpdates

(9) API 내용에서 from":{"id":값, 에서 ID값 문자를 복사하여 입력칸에 붙여넣으세요

(10) "설정 업데이트" 를 눌러 저장한 뒤 "테스트 메시지 전송" 버튼을 눌러주세요

설정이 올바르게 적용되었는지 확인하기 위해 테스트 메시지를 전송합니다.
